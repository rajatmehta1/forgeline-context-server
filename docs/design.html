High-Level Architecture

Component Overview

Component Reference

src/server.py

MCP Server Entry Point

Defines all tools, resources, and prompts using FastMCP decorators. Handles startup (KG connect) and shutdown lifecycle. All logging routes to stderr for MCP stdio compatibility.

src/services/context_builder.py

Context Builder

Orchestrates all data sources into a FileContext. Calls KG service and policy service in sequence. Each step is independently fault-tolerant — KG failure doesn't prevent policy delivery.

src/services/knowledge_graph.py

Knowledge Graph Service

Async Neo4j driver wrapper with TTL cache and retry logic (tenacity, 3 attempts, exponential backoff). Contains Cypher queries for modules, functions, classes, boundaries, sensitivity, and dependencies.

src/services/policies.py

Policy Service

In-memory policy engine. Ships 14 default rules across 5 categories. Supports YAML-based custom profiles. Filters rules by architecture layer. No database dependency.

src/models/schemas.py

Pydantic Schemas

All domain models: FileContext, PolicyRule, FunctionPattern, ClassPattern, LayerBoundary, SensitiveField. FileContext.to_prompt_context() serializes to markdown text.

src/config/settings.py

Settings

Pydantic-settings class that reads from environment variables and .env file. Configures Neo4j, PostgreSQL, transport mode, cache TTL, and optional ForgeLine cloud API.

Full MCP Surface Reference

Tool
get_context_for_file

Primary tool. Returns complete governance context: security rules, arch constraints, existing patterns, sensitivity rules, approved packages.

Tool
get_security_rules

Returns only security rules for a given layer. Useful when the AI only needs security context without full file context.

Tool
get_existing_patterns

Queries Neo4j for exported functions and classes near a file path. Prevents the AI from reinventing existing utilities.

Tool
get_architecture_map

Returns the full architecture boundary graph — which layers can and cannot import from which others.

Tool
check_dependency

Checks a package name against the KG. Detects phantoms (hallucinated packages), trust score, CVE count, and approval status.

Tool
get_data_sensitivity

Returns PII/PHI/PCI/FINANCIAL/CREDENTIAL field classifications and their handling constraints for the target module.

Resource
forgeline://policies/active

All active policy rules from the default profile, organized by category. Read-only reference document.

Resource
forgeline://architecture/graph

Full architecture boundary graph from Neo4j. Falls back to a hardcoded default layered architecture if KG is unavailable.

Resource
forgeline://standards/style-guide

Coding standards and style rules for the service layer. Driven by STYLE-category policy rules.

Prompt
code_with_governance

Template that instructs the AI to call the three primary tools before writing any code. Args: task, file_path, language.

Caching Strategy

TTLCache — KnowledgeGraphService

Pattern queries (functions, classes), architecture boundaries, and dependency data are cached in a TTLCache. Cache key includes repo name + directory prefix. Default: 500 entries, 5-minute TTL.

TTLCache — PolicyService

Policy rule lookups are cached separately. Default: 100 entries, 5-minute TTL. Both TTL and max sizes are configurable via CACHE_TTL_SECONDS and PATTERN_CACHE_MAX_SIZE env vars.
